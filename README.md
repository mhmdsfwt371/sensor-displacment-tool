# أداة توزيع الحساسات والجيت واي
### Sensor & Gateway Layout Tool

أداة ويب من **ملف واحد** لتقييم الموقع من الرسمة، توزيع الحساسات والجيت واي
تلقائيًا، وإخراج الأعداد والرسمة وجداول التركيب والتوريد — بالعربي والإنجليزي.

---

## إيه اللي بتعمله

| الخطوة | إيه اللي بيحصل |
|---|---|
| ترفع صورة الرسمة | الأداة بتنضّفها وتقرا حدود الغرف لوحدها |
| أو ترسم من الصفر | حوائط وأبواب بقفل زوايا وسناب نص متر وأطوال حية على كل ضلع |
| تعدّل أي حاجة | أداة تعديل: اسحب غرف وحساسات وأركان، واحذف بضغطة |
| تدوس **شغّل كل حاجة** | بتحدد الغرف وتحسب المساحات وتوزّع وتحط الجيت واي |
| تراجع وتعدّل | زراير **+** و **−** لكل غرفة، وتعديلك مبيضعش لو وزّعت تاني |
| تطلّع المخرجات | صورة للمبيعات · جدول تركيب للأوبريشن · قائمة توريد للمخزن |

**المعايير:** حساس لكل **٢٥ م٢** · **جيت واي مستقل لكل غرفة**
الحساس دايرة حمراء · الجيت واي مربع أزرق · كلهم بمقياس الرسمة.

---

## التشغيل السريع

نزّل `index.html` واضغط عليه مرتين. خلاص — بيشتغل من غير أي تنصيب،
والحفظ والفتح بملف `.json`.

## التشغيل بنظام دخول

محتاج رابط + مشروع فايربيز. الخطوات كاملة في **[SETUP.md](SETUP.md)**.

---

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | الأداة كاملة — بدون أي تبعيات |
| `SETUP.md` | دليل التنصيب خطوة بخطوة |
| `firestore.rules` | قواعد أمان قاعدة البيانات |
| `firebase.json` | إعداد الاستضافة على فايربيز |
| `.gitignore` | يمنع رفع المفاتيح السرية |
| `.nojekyll` | يمنع جيت هب من معالجة الملفات |

---

## تنبيه أمان

القيم الأربعة في `FIREBASE` **مش أسرار** — بتتعرض في المتصفح بطبيعتها.
الحماية من **قواعد فايرستور** و**النطاقات المسموحة**.

اللي **سرّي فعلًا** هو ملف **حساب الخدمة**
(`*-firebase-adminsdk-*.json`) — ما يترفعش أبدًا. `.gitignore` بيمنعه.
